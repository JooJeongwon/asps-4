## 사용 경험과 오류 복구

- MCP는 도구명과 JSON 인자가 고정되어 구조화된 호출과 일정한 결과 형식이 장점이었다. MCP 등록, 읽기 승인 모드, 서버 환경 변수 전달을 먼저 확인해야 했다.
- CLI는 명령과 옵션이 보여 재현·디버깅이 쉬웠다. Codex 셸 샌드박스의 네트워크 접근과 `.env` 전달을 맞춘 뒤 세 시나리오 모두 한 번의 호출로 성공했다.
- 초기 실행에서는 MCP 인증 환경 변수 누락, CLI 네트워크 차단이 각각 발생했다. 수정 후 동일 조건으로 재실행했고 실패 회차를 최종 성능표에 섞지 않았다.

이번 수치는 한 팀과 한 입력 세트의 관찰값이다. CLI가 이번 조건에서 토큰과 시간이 적었지만, 이를 모든 팀·모든 작업의 일반적 우위로 확대하지 않는다.
